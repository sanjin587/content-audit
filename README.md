# Content Audit

一个面向内容创作者的增长审计 Skill。

它判断一条内容能不能让用户：

- 停下来并继续看
- 产生“这不就是我吗”的共鸣
- 带走可以直接使用的价值
- 记住作者、愿意关注
- 产生收藏和传播

它审计的是用户行为，不是文字是否通顺；会根据用户意图进入审计、改写、对比或数据复盘模式。

## 支持内容

- 抖音口播稿和短视频脚本
- X / Twitter 帖子
- 公众号文章
- 小红书内容
- AI、创业和商业类内容

## 工作模式

- 审计：只指出问题，默认不改全文
- 改写：先找最大瓶颈，再按用户要求改写并复查
- 对比：明确选择更适合的平台版本
- 数据复盘：从发布数据定位漏斗中的最大异常，并设计下一轮实验

## 审计框架

Skill 使用六个维度评分：选题力、点击力 / 停留力、共情力、价值力 / 收藏力、关注力和传播力；同时检查“看到 → 停留 → 共鸣 → 得到价值 → 关注 → 传播”的用户行为漏斗。

不同平台有额外规则：短视频重点看前 3–5 秒，X / Twitter 重点看第一句话和可引用性，公众号重点看标题、开头、故事、观点、方法和结尾。

## 使用方式

将本目录作为一个 Skill 加载到支持 Codex Skills 的 Agent 环境中，并在需要审计内容时提供稿件和平台类型。完整行为约束见 [SKILL.md](SKILL.md)。
