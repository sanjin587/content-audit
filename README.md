# 内容导演 / Content Director v2.0.1

一个面向内容创作者的选题导演、增长审计、改写、版本对比与数据复盘 Skill。

它优化的不是“文字是否更漂亮”，而是用户行为：

> 看到 → 停下来 → 看下去 → 共鸣 → 得到价值 → 收藏 / 关注 → 评论 / 转发

## v2.0 升级

- 保留原六维 60 分内容审计，以及审计、改写、对比、数据复盘四种模式
- 新增独立的八维 80 分选题导演；禁止与内容分合并
- 改写前先提取 `protected_elements`，保护事实、归属、作者观点和个人声音
- 把“改动幅度”和“表达形态”拆开，支持轻改 / 中改 / 重构与原声 / 口喷版组合
- 审计固定为七部分输出，改写显示关键修改前后对照
- 提供机器可读的输入输出 JSON Schema、样例与人工验收清单
- 保留抖音、视频号、小红书、X / Twitter、公众号等平台专项判断

## 工作模式

- **选题导演**：在成稿前用八维 80 分判断用户相关性、停留潜力、证据能力与系列潜力
- **内容审计**：用六维 60 分定位现有稿件的最大掉人点，默认不改全文
- **改写**：先保护事实和作者声音，再针对最大瓶颈修改并二次检查
- **对比**：明确选择更适合当前目标和平台的版本
- **数据复盘**：从发布数据定位漏斗中的最大异常，并设计单变量实验

## 使用方式

将本目录作为一个 Skill 加载到支持 Codex Skills 的 Agent 环境中。可以直接说：

- “内容导演，帮我判断这个选题。”
- “内容审计，先只审计，不要改。”
- “保护原来的事实，给我一版中改口喷版。”
- “对比 A/B 两版，必须选一个。”
- “根据发布数据，只找下一轮最该测的一个变量。”

机器调用方可参考 [references/protocol.md](references/protocol.md) 和两个 Schema。普通对话无需强制使用 JSON。

## 边界

本仓库提供内容判断协议与 Skill，不包含自动发布、自动剪辑、热点抓取、登录账户或生产数据库。分数和改写结果不代表已经获得真实发布效果。
